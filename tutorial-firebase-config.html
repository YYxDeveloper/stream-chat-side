functions:config:set 完整教學

針對 stream-chat-side 專案（Issue #1），說明如何用 Firebase CLI 安全管理 Stream Chat API 金鑰，取代不安全的 .env 硬編碼做法。

總覽

本教學對應 stream-chat-side / Issue #1：Firebase Auth + Stream Chat Token 整合

架構流程
Firebase CLI設定金鑰
→
Firebase Config加密儲存於雲端
→
Cloud Function執行時讀取 config
→
Stream Chat SDK生成 token
→
Flutter App收到 token
ℹ️金鑰永遠不出現在程式碼或 git history。Firebase 在 server 端安全儲存，Function 執行時自動注入。

為何不用 .env 檔案？

比較三種常見金鑰管理方式

方式安全性適用場景此專案
.env 本機檔案 高風險
容易被誤 commit		 本機開發臨時用 不推薦
硬編碼在程式碼 極危險
公開於 git history		 絕對不要用 禁止
functions:config:set 安全
Firebase 加密儲存		 Firebase Functions 推薦
🚨STREAM_API_SECRET 一旦洩漏於 git，攻擊者可偽造任意 user 的 Stream token。發現即須立刻 rotate！

BASH
# 刪除舊 secret（發生洩漏時使用）
firebase functions:config:unset stream.secret

# 設定新 secret
firebase functions:config:set \
  stream.secret="新的_STREAM_API_SECRET"

# 重新部署才生效
firebase deploy --only functions
⚠️修改 config 後必須重新部署 Functions 才會生效。每次 rotate 金鑰都要重跑部署。
3

在 Firebase Functions 讀取金鑰

使用 functions.config() 讀取，不需要 process.env

index.js（4 個 Functions）
package.json
JAVASCRIPT — functions/index.js
const functions = require('firebase-functions');
const admin = require('firebase-admin');
const { StreamChat } = require('stream-chat');

admin.initializeApp();

// ✅ 從 Firebase Config 讀取金鑰（非 process.env）
const streamKey    = functions.config().stream.key;
const streamSecret  = functions.config().stream.secret;
const serverClient = StreamChat.getInstance(streamKey, streamSecret);

// ── Function 1：建立 Stream User 並回傳 token ──────
exports.createStreamUserAndGetToken = functions.https.onCall(async (data, context) => {
  if (!context.auth) throw new functions.https.HttpsError(
    'failed-precondition', '必須先登入 Firebase Auth'
  );
  const { uid, token: { name, email, picture } } = context.auth;
  try {
    await serverClient.upsertUser({ id: uid, name, email, image: picture });
    return serverClient.createToken(uid);
  } catch (e) {
    throw new functions.https.HttpsError('aborted', e.message);
  }
});

// ── Function 2：取得現有 user 的 token（登入用）──
exports.getStreamUserToken = functions.https.onCall(async (data, context) => {
  if (!context.auth) throw new functions.https.HttpsError('failed-precondition', '未登入');
  return serverClient.createToken(context.auth.uid);
});

// ── Function 3：撤銷 token（登出前呼叫）─────────
exports.revokeStreamUserToken = functions.https.onCall(async (data, context) => {
  if (!context.auth) throw new functions.https.HttpsError('failed-precondition', '未登入');
  await serverClient.revokeUserToken(context.auth.uid);
  return { success: true };
});

// ── Function 4：Firebase 帳號刪除時同步刪除 Stream user
exports.deleteStreamUser = functions.auth.user().onDelete(async (user) => {
  await serverClient.deleteUser(user.uid);
});

4

本機 Emulator 測試

在本機模擬 Firebase Functions，不需要每次部署到雲端

BASH
# 1. 先將 config 匯出為本機檔案（Emulator 讀取用）
firebase functions:config:get > .runtimeconfig.json

# ⚠️ 務必加入 .gitignore
echo ".runtimeconfig.json" >> .gitignore

# 2. 啟動 Functions Emulator
firebase emulators:start --only functions

# Emulator UI: http://localhost:4000
# Functions:   http://localhost:5001/stream-auth-2026/us-central1/
🚨 .runtimeconfig.json 包含明文 secret，必須加入 .gitignore！此檔案僅用於本機開發。
ℹ️ Flutter 端連到 Emulator 需額外設定：在 main.dart 初始化後加上 FirebaseFunctions.instance.useFunctionsEmulator('localhost', 5001);

Flutter App 呼叫 Firebase Function

使用 cloud_functions 套件呼叫 callable function

登入流程
登出流程
pubspec.yaml
DART — 登入並取得 Stream token
import 'package:firebase_auth/firebase_auth.dart';
import 'package:cloud_functions/cloud_functions.dart';
import 'package:stream_chat_flutter/stream_chat_flutter.dart';

Future<String> signInAndGetStreamToken() async {
  // 1. Firebase Google Sign-In
  final googleUser = await GoogleSignIn().signIn();
  final googleAuth = await googleUser!.authentication;
  final credential = GoogleAuthProvider.credential(
    accessToken: googleAuth.accessToken,
    idToken: googleAuth.idToken,
  );
  await FirebaseAuth.instance.signInWithCredential(credential);

  // 2. 呼叫 Firebase Function 取得 Stream token
  final callable = FirebaseFunctions.instance
      .httpsCallable('createStreamUserAndGetToken');
  final result = await callable.call();
  final streamToken = result.data as String;

  // 3. 連接 Stream Chat
  final client = StreamChatClient('你的_STREAM_API_KEY');
  await client.connectUser(
    User(id: FirebaseAuth.instance.currentUser!.uid),
    streamToken,
  );
  return streamToken;
}
DART — 登出（先撤銷 token）
Future<void> signOut(StreamChatClient client) async {
  // 1. 先撤銷 Stream token（重要！）
  await FirebaseFunctions.instance
      .httpsCallable('revokeStreamUserToken')
      .call();

  // 2. 斷開 Stream Chat 連線
  await client.disconnectUser();

  // 3. 登出 Firebase
  await FirebaseAuth.instance.signOut();
}

安全 Checklist

部署前確認所有項目，點擊打勾

  • STREAM_API_SECRET 未出現在任何程式碼或 .env 中
  • .runtimeconfig.json 已加入 .gitignore
  • firebase functions:config:set 已成功執行
  • firebase functions:config:get 確認 key/secret 存在
  • Functions 已部署（firebase deploy --only functions）
  • 本機 Emulator 測試通過（login / logout 完整流程）
  • 未登入呼叫 Function 時，回傳 failed-precondition
  • 登出時 revokeStreamUserToken 已被呼叫
  • stream_chat_flutter 僅在 client 端存 API Key，不存 Secret
  • Firebase Functions git history 中無任何明文 secret
